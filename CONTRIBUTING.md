# Contributing

Pull requests and bug reports are welcome.

## Bug reports and ideas

- Open a GitHub issue, or use **Report a bug** in the app (Settings → Report a Bug), which emails support@mydailychronicles.com.
- Issues are public. Don't include passwords, recovery keys, health information or other personal data.
- Report security problems privately to support@mydailychronicles.com, not in an issue.

## Pull requests

- Fork the repository and make your change on a branch in your fork.
- Run `npm run test` and `npm run build` before you open the pull request.
- Follow the project's conventions in `CLAUDE.md`, especially the UI design rules.
- The owner may accept, change, decline or close any pull request.
